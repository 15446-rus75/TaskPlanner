# Планировщик учебных задач

Desktop-приложение для управления учебными задачами, дедлайнами и приоритетами. Разработано в рамках дисциплины **Основы проектной деятельности** и продолжает свое развитие в рамках **Ознакомительной практики** в ИКНК СПбПУ.

## Для кого
В первую очередь приложение адресовано **студентам**, которым нужно систематизировать учебную нагрузку, фиксировать сроки сдачи и не терять задачи в потоке информации.

## Что умеет
### Управление задачами
- Создание, редактирование и удаление задач
- Указание дисциплины, дедлайна, приоритета и описания
- Фильтрация: все / на сегодня / просроченные, а также по приоритету
- Сортировка по дате, приоритету и статусу выполнения
- Блок статистики и автоматическое сохранение в JSON
- Встроенная система резервного копирования данных для предотвращения потерь
### Геймификация учебного процесса
- **Система уровней и опыта:** Получение очков опыта за выполнение задач
- **Серия дней:** Отслеживание непрерывной серии дней с выполненными задачами
- **Система достижений:** Разблокировка скрытых наград за различные успехи
- **Интерактивная карта кампуса:** Визуальное открытие новых локаций СПбПУ по мере роста уровня
- **Персонализация:** Возможность задать свое имя и отслеживать текущее звание/ранг
### Интеграция с СДО
- **Быстрый доступ к порталам:** Выбор института формирует ссылку для перехода на его СДО
